# Pixel — Anniversaires créatifs IA

Site vitrine responsive en français, sans dépendances ni compilation.

## Développement

Depuis `/workspace/ia-birthday` :

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Les fichiers `index.html` et `assets/` peuvent être hébergés sur tout hébergement statique HTTPS.
